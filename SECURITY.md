# Security policy

Team Relay crosses machine, identity, model, and filesystem trust boundaries.
Please do not include credentials, private prompts, attachments, or exploit
details in a public issue.

Use GitHub's private vulnerability-reporting flow for this repository when it
is available. If private reporting is unavailable, contact the maintainer
through their GitHub profile to arrange a private channel before sharing any
exploit details.

Include the affected version or commit, deployment shape, reproduction steps,
and impact. Remove secrets and personal data. Maintainers will acknowledge a
complete report, reproduce it privately, coordinate a fix and disclosure, and
credit reporters who want attribution.

The current developer preview has not received an independent security audit.
See [docs/security-model.md](docs/security-model.md) for trust boundaries and
known limitations.
